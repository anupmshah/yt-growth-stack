# Contributing

Thanks for helping build YT Growth Stack.

1. Open or choose an issue with acceptance criteria.
2. Create a focused branch.
3. Read `AGENTS.md` and the relevant `skills/*/SKILL.md`.
4. Make the smallest coherent change.
5. Run `npm run verify`.
6. Open a pull request using the template and include evidence.

Do not include credentials, private research datasets, or copyrighted source content beyond what is legally necessary for tests. By contributing, you agree that your contribution is licensed under MIT.
